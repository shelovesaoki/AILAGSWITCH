// getting started

Setup guide

01
Download the .exe
Click the download button above. The file is portable — no installer needed. Save it anywhere you like, e.g. your Desktop.
02
Run as Administrator
Right-click LagSwitch.exe → Run as administrator. This is required so the app can interact with your network adapter drivers.
03
Select Your Network Adapter
In the dropdown at the top, pick the adapter your game uses. Usually it's your Ethernet or Wi-Fi adapter — check Task Manager → Performance tab if unsure.
04
Configure Your Settings
Set your desired lag spike amount (ms), packet loss (%), and optional bandwidth cap. You can save these as presets for quick switching.
Spike Delay : 200–2000ms (recommend 500ms to start) Packet Loss : 0–100% (10–30% for subtle effect) Bandwidth Cap: optional (leave blank for no cap)
05
Assign a Hotkey (Optional)
Go to Settings → Hotkeys and bind a key combo like F8 or Ctrl+L to toggle the lag on/off without alt-tabbing out of your game.
06
Hit the Big Pink Button
Press ACTIVATE to start the lag switch. The button turns red and the status bar shows ACTIVE. Press again (or your hotkey) to instantly restore normal network.
Emergency reset: if the app freezes while active, open CMD and run:
netsh winsock reset netsh int ip reset
Then restart your PC. Your connection will be fully restored.
